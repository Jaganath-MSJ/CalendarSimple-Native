# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep
discussions about the work. Harassment, insults and personal attacks are not
accepted in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer through
[GitHub's private vulnerability reporting](https://github.com/Jaganath-MSJ/CalendarSimple-Native/security/advisories/new)
form, or by contacting [@Jaganath-MSJ](https://github.com/Jaganath-MSJ) on
GitHub. Reports are kept confidential. The maintainer may remove comments,
close threads or block participants who break this code.
